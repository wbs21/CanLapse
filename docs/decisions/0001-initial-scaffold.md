# 0001 — 初始骨架与技术栈待定

- 状态：已接受
- 日期：2026-02-14

## 背景

需要为 CanLapse 建立一个仓库起点。项目的具体用途、目标平台与技术栈尚未确定。

## 决定

先建立一个**与技术栈无关**的最小骨架：README、LICENSE、.gitignore、.editorconfig、
CHANGELOG，以及 `src/`、`tests/`、`docs/` 三个占位目录。

不引入任何语言运行时、包管理器或构建配置，避免在栈未定前产生需要推翻的约定。

## 后果

- 可以直接在任何技术栈上落地，无需先清理脚手架。
- `src/` 与 `tests/` 当前为空，需要后续 ADR 记录选型结果。

## 后续

1. 明确 CanLapse 的用途与目标用户（待补充）。
2. 在此目录新增 ADR 记录技术栈选型。
3. 补充安装、运行、测试命令到 README。
