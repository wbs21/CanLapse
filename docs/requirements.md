# CanLapse 需求与最终方案汇总（v1.0）

> 本文是 v1.0 的需求基线，由产品方确定。实现范围以本文为准；
> 与技术实现相关的架构决策另见 [docs/decisions/](decisions/)。

## 产品定位

面向手绘创作者（SAI2 > PS > CSP > Krita）的**画布窗口专用缩时录制工具**。

核心机制：DWM 窗口缩略图捕获指定 HWND 画布窗口；画面差分判断，按需保存 PNG 到本地缓存；
录制结束后使用 OpenH264 批量编码合成 MP4。OpenH264 编码器采用自编译最小方案，只保留编码，去除解码。

> 设计约束：**单页面小巧主窗口，无独立设置面板；录制时主窗口最小化，仅保留悬浮操作条；
> 无自动画布识别，依靠用户拾取窗口。**

---

## 一、整体架构方案

1. **捕获方案**：鼠标拾取 HWND 窗口 + DWM 缩略图捕获
   - 拾取后实时小预览图；边缘像素方差采样做**辅助提醒**（仅提示，不强制阻断）
   - 用户可以忽略警告继续录制（部分教学场景需要连同面板录制）
2. **快照存储**
   - 录制会话独立缓存文件夹，命名格式：`{时间}_{会话名称}`
   - 保存：`frame_xxxx.png` + `markers.json`（标记帧序号、录制时间、可选备注）
   - 帧密度：1~8fps（快照保存频率，静止画面不会保存帧）
   - 像素差异阈值：0.00~0.05，控制画面变化敏感度
3. **录制交互**
   - 点击【开始录制】→ 主窗口自动最小化，弹出悬浮条
   - 悬浮条：`⏸暂停 🏷标记 ⏹停止 | 时长 | 帧计数`，可拖动、无边框
   - 停止录制 → 主窗口自动恢复，进入视频合成流程
4. **导出机制（录制参数与导出参数相互独立，缩时核心）**
   - 录制：帧密度（快照保存频率）
   - 导出：播放帧率（5/10/15/20/24fps）、画质高/中/低、输出路径
   - 复选框：**合成成功自动清理缓存（默认勾选）**
   - 缓存提醒：仅在【导出视频参数】面板内静态文字提示，**不做磁盘扫描、无容量统计、不可关闭提示**
   > 💡提示：如果取消勾选「合成成功自动清理缓存」，PNG 帧图片会保留在缓存目录，
   > 占用磁盘空间，请记得定期手动删除缓存。
5. **历史缓存会话**（折叠面板）
   - 列表展示：会话名称｜帧数量
   - 每条会话操作：【重新导出】【打开文件夹】【删除】
   - 正在录制/合成中的会话：删除按钮置灰，禁止删除
6. **弹窗（仅 2 个，不新增任何页面）**
   - ❓如何定位窗口：帮助弹窗，4 款绘画软件浮动画布操作指引
   - 🔍预览窗口：大图弹窗，完整查看拾取窗口捕获画面

## 二、单页面 UI 布局（固定，小巧，无高级设置面板）

> 默认窗口尺寸：460×380，最小限制 400×320，全部控件垂直排布，无 Tab 分页

1. 顶部：软件名称
2. 拾取模块（永久展开）
   - 横向按钮组：🎯拾取窗口｜🔍预览窗口｜❓如何定位窗口
   - 预览缩略图（160×100）
   - 拾取状态提示：
     - 尚未选择画布窗口
     - ✅已选中画布窗口
     - ⚠️检测到窗口包含工具栏，画布未浮动 + 内联链接【如何定位窗口】
3. 录制参数【折叠面板，默认展开】
   - 帧密度滑块：1~8 fps
   - 像素差异阈值滑块：0.00~0.05
4. 导出视频参数【折叠面板，默认折叠】
   - 缓存静态提醒文字（固定）
   - ☑合成成功自动清理缓存
   - 播放帧率下拉选择
   - 画质档位下拉选择
   - 输出路径输入框 + 【选择】按钮
5. 历史缓存会话【折叠面板，默认折叠】
   - 会话列表，每行：名称｜帧数量，附带【重新导出】【打开文件夹】【删除】
6. 底部操作区（永久可见，状态动态切换）
   - Idle 待机：【开始录制】主按钮
   - Recording 录制中：提示文字（主窗口已最小化，请使用悬浮条）
   - Encoding 合成中：进度条、已处理帧计数、【取消合成】按钮

## 三、帮助弹窗：如何定位画布窗口

> 弹窗标题：如何定位画布窗口
> 导语：想要只录制画布，需要把画布拆成独立浮动窗口，再使用【拾取窗口】选中画布。

- **SAI2**：视图 → 新建浮动视图
- **Photoshop**：拖拽画布标签向外拉出，脱离主框架
- **CSP/优动漫 PAINT**：拖拽画布标签分离，或 视图 → 新建视图
- **Krita**：窗口 → 新建窗口

> 💡提示：拾取后查看预览窗口，如果画面包含工具栏/图层面板，说明画布没有浮动。

## 四、核心容错与规则

1. **窗口有效性**：录制循环持续检测目标 HWND；画布窗口关闭，自动暂停并提示
2. **捕获容错**：单帧捕获/保存失败，仅跳过当前帧，UI 提示丢帧数量，**不中断录制、不崩溃**
3. **边缘检测**：仅辅助提示，**允许用户强行继续录制**，存在误报，以预览画面为准
4. **缓存**：删除会话会删除整个会话缓存目录；正在录制/编码会话禁止删除
5. **硬编码常量**（v1.0 不提供 UI 调整入口，移除高级设置面板）
   - 悬浮条透明度、悬浮条置顶开关、边缘检测阈值，全部写死常量；后续版本按需再加 UI 配置

## 五、功能优先级（v1.0 P0，全部需要实现）

1. 拾取 HWND 窗口、实时预览、边缘辅助检测、【如何定位窗口】帮助弹窗
2. DWM 捕获、画面差分、帧密度 1~8fps，PNG 缓存保存、markers.json 标记记录
3. 悬浮条：暂停 / 标记 / 停止；录制时主窗口最小化，停止后主窗口恢复
4. OpenH264 批量合成 MP4，导出参数独立于录制参数
5. 历史缓存会话管理：重新导出、打开目录、删除会话
6. 录制前置校验：HWND 有效性；单帧失败容错
7. 导出面板缓存静态提醒（仅此处出现，无扫描，不可关闭）

## 六、明确不做（v1.0 范围裁剪，控制复杂度，保持界面小巧）

1. ❌ 无目录遍历、无缓存大小统计、无磁盘容量告警
2. ❌ 无高级设置折叠面板，无设置窗口
3. ❌ 无全局快捷键
4. ❌ 无音频录制
5. ❌ 无水印叠加
6. ❌ 无自动识别绘画软件、自动查找画布 HWND
7. ❌ 视频剪辑、GPU 硬编码

## 七、产品风险与注意点

1. **用户教育**：SAI2 用户上手最简单；PS/CSP 次之；Krita 用户习惯一体化界面，
   需要依靠帮助弹窗引导创建浮动画布
2. **边缘检测存在误报**：紧贴画布边缘作画会误报，必须保留忽略警告的能力
3. **DWM 依赖**：桌面合成必须开启；提前处理 DWM 异常捕获失败情况
4. **权限**：读写缓存目录，处理文件写入失败异常
