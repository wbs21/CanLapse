## 八、运行中才发现的缺陷（提醒：不要只靠读代码验收）

1. 悬浮条的时长/帧计数写在**无标题栏窗口的标题**里 → 用户根本看不见
2. exe 是控制台子系统 → 双击弹黑框
3. `CanLapse.exe` 与 `canlapse.exe` **大小写同名互相覆盖** → GUI 入口从未生效
4. 重新导出的产物落在会话目录内 + 自动清理 → **刚导出的视频被自己删掉**
5. 大图预览弹窗创建在绘画软件**后面** → 用户以为"打不开"
6. 命令行录后台窗口时新规则导致**一直暂停、一帧不出** → 补 `--no-fg-pause`
7. 预览占位文字用窗口 DC 的默认 System 位图字体 → 高 DPI 下巨大且被 160×100 裁掉；
   修的时候又踩到 `DT_CALCRECT` 会收窄矩形 → 后续 `DT_CENTER` 按窄框算，文字贴左
8. 抓帧失败时旧预览没清 → 状态栏说"抓不到"，画面上还留着上一个目标的图，用户以为拾取成功了
9. 拾取结束后的重绘只调 `InvalidateRect`，而主窗口刚从小化恢复，WM_PAINT 时机不保证 →
   改为 `InvalidateRect` + `UpdateWindow` 同步重绘（自动化实测日志出现 `DO_PICK 同步重绘完成`）
10. `do_pick` 把用户点中的**画布子窗口**用 `root_of` 换成了主窗口 → 预览里出现工具栏和颜色面板，
    用户看到的就是"没锁到画布"。改成保留点中的窗口（子窗口交给抓帧器做 rcSource 裁剪）
11. 抓帧宿主没加 `WS_EX_TOOLWINDOW` → 任务栏图标的悬停预览里会堆出一排"CanLapse 抓帧宿主"
12. 拾取时的那次左键会传给绘画软件（SAI2 会在画布上留一个点）→ 改用 `WH_MOUSE_LL`
    低级钩子吞掉这次点击，并顺带解决"快速点击被 60ms 轮询漏掉"
13. 日志默认不落盘（只有 panic 才有 `crash.log`）→ 加 `src/log.rs`，debug 构建默认写
    `%LOCALAPPDATA%\CanLapse\canlapse.log`，记录拾取层级/点击结果/抓帧尺寸与错误

## 附：版本信息（RT_VERSION）读不出来的真正原因（已修复）

**现象**：注入后 exe 里的 `RT_VERSION` 是**空壳** —— 枚举 exe 自身资源得到：

```
RT_ICON       : 名字数=7  语言=0409×7        首个大小=645 字节
RT_GROUP_ICON : 名字数=1  语言=0409          首个大小=104 字节
RT_VERSION    : 名字数=1  语言=(空)          首个大小=0 字节     ← 空壳
RT_MANIFEST   : 名字数=1  语言=0409          首个大小=1661 字节
```

即：该类型下有一个**名字项**，但**没有语言子项、数据为 0 字节**。
因此 `.NET FileVersionInfo`（以及资源管理器"详细信息"）读出全空 —— 与读取方无关。

**两个真根因（都在 `.rc`，不在注入/链接环节）**：

1. **漏了 `#define VS_VERSION_INFO 1`**。它在 `winver.h` 里就是 1；不 `#include <windows.h>`
   时这个常量没有定义，`VERSIONINFO` 语句被 rc.exe 当成无效内容，**不报错**，
   只写下一个空壳 `RT_VERSION`。
2. **`.rc` 文件编码**。UTF-8 + `#pragma code_page(65001)` 时 rc.exe 退出码 0，
   但产出的 `.res` 只有 **776 字节**（几乎为空）；改存 **UTF-16LE**（无 `#pragma`）后
   同一内容产出约 **23900 字节**，图标与版本信息都正常。

**为什么会误判到注入逻辑**：中间 `res.dll` 里就已经是空壳（`types=1`），
看起来像 `link.exe` / `UpdateResourceW` 的问题；实际 `lib.exe` 很早就能正常吸收
（产出 1994 字节 `.lib`）。教训：先确认**源 `.res` 本身**有 3 种资源类型、`RT_VERSION` 非 0 字节，
再怀疑下游。

**现在怎么用**：`pwsh -File tools\build.ps1`（cargo build 后自动注入）。
注入结果 `资源类型=3 已复制=9 写回=True`，两个 exe 的 `VersionInfo` 均读出 `1.0.0.0`。

### 2) 真实绘画过程的缩时：**首次成功**

目标：CSP 画布子窗口 `0x380BC6`（1051×826），被动录制 90 秒（2fps，阈值 0.002）：

```
录制结束：36 帧，0 个标记，丢弃 0，耗时 01:30
合成：36 帧 -> 1050x826，418,620 字节
ffprobe：h264 / High / 1050x826 / nb_read_frames=36 / duration 3.000000 秒
交叉核对：36 ÷ 12fps = 3.000 秒  ✔ 精确吻合
```

帧序可见真实笔触推进（红色加粗 → 清空 → 蓝色粗笔触 → 成形 → 红线叠加），
证据：`csp_timelapse.mp4`、`csp_session_montage.png`。

**这一项此前是唯一未达成的实质验证**（在真实绘画软件上最多只得到 2 帧），现已关闭。
